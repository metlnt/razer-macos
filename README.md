# Naga Control

Нативное macOS-приложение для настройки мыши **Razer Naga Trinity** (RZ01-0241, USB `1532:0067`) без Razer Synapse.

Все настройки записываются прямо во встроенную память мыши, поэтому работают и без запущенного приложения.

## Возможности

- **Кнопки** — переназначение любой кнопки: клик мыши, сочетание клавиш (с записью), DPI ±, пресеты для браузера и macOS. Два слоя (обычный и Hypershift), боковые панели на 2, 7 и 12 кнопок, наклон колеса влево/вправо.
- **DPI** — до 5 стадий (100–16000, раздельно X/Y), живой индикатор текущего DPI, частота опроса 125/500/1000 Гц.
- **Подсветка** — 3 зоны (колесо, логотип, боковая панель): статичный цвет, дыхание (1/2/случайные цвета), спектр, реакция на нажатие, яркость.

## Сборка

Нужны macOS 14+ и Xcode (Swift 5.10+).

```sh
./build-app.sh
open build/NagaControl.app
```

Приложение общается с мышью USB control-запросами (`IOUSBHost`), поэтому разрешение «Мониторинг ввода» не требуется.

## Устройство репозитория

| Путь | Что там |
|---|---|
| `NagaControl/Sources/NagaKit` | протокол Razer: 90-байтные отчёты, команды DPI, подсветки, кнопок |
| `NagaControl/Sources/NagaControl` | SwiftUI-интерфейс |
| `NagaControl/Icon` | иконка и скрипт, который её рисует |
| `CAPABILITIES.md` | расшифровка протокола, найденная опросом мыши |
| `razer_proto.py` | Python-версия протокола для экспериментов (`uv pip install hidapi`) |
| `backup-original.json` | заводские назначения кнопок, DPI и подсветки |

## Осторожно

Команды класса `0x06` прошивка принимает не глядя, а `06:8D` подвешивает интерфейс мыши (лечится переподключением). В приложении они не используются.
